# 4H-Alarm Robotics Calendar

This is a custom-built calendar application to assist in tracking events, shop days, and attendance.

I'll fill this out more as I finish the application.

https://alarmrobotics.com

## Downloading the latest build

Every push to `master` builds the project on Ubuntu 24.04 (x86_64) with LDC and publishes the binary to a rolling `latest` release. Download it with:

```sh
curl -L -o alarmcal https://github.com/schveiguy/alarmcal/releases/latest/download/alarmcal
chmod +x alarmcal
```
